# Deferred nursery prototype

These staged-funding/care modules were drafted during the nursery proposal and
archived when the scope changed to immediate egg hatching. They are not mapped
into the Roblox game by Rojo and have not been deployed. The active equivalents
are `src/shared/EggCatalog.lua`, `src/server/HatchProgress.lua`, and
`scripts/HatchProgress.spec.lua`.

Restore or adapt this work only as part of a separately scoped nursery feature.
