## 1. Units and scale

Three coordinate spaces. Every number in this file names its space.

| Space | Meaning |
|---|---|
| **View px** | Offset pixels in the inset interactive root (inside `CoreUISafeInsets`). Reference view: **1920×1080**. |
| **Deck units (u)** | The deck body is **1600×800 u** (2:1). `s = deckWidthPx / 1600`. All shell rects are in `shell.json` → `layout`. |
| **LCD px** | The screen inside the glass is **848×608** at `s = 1`. Every per-screen table below is in LCD px, origin at the LCD's top-left. |

**Deck scale.**

```
s = min((rootW - 48) / 1600, (rootH - 48 - 12) / 800)     -- 24 px margin; 12 for the shoulder nubs
s = clamp(s, _, 1.2)
deck is centred in the root, then moved 10 px down (the nubs sit above the body)
```

At 1920×1080, `s = 1.0`, the deck is at view (160, 150) and the LCD at view (536, 246). At 1649×971, `s = 1.0` as well.

**LCD layout mode.**

| Mode | When | How |
|---|---|---|
| **Regular** | `s ≥ 0.75` | Build every screen at 848×608 and put one `UIScale` (= `s`) on the LCD content frame. Type scales with it. |
| **Compact** | `s < 0.75` (phone landscape) | The deck scale changes to `s = (rootH - 8) / 608` so **the LCD fills the safe height and the case bleeds past the root**. Screens use the compact layouts in section 7, authored at **417×299** with `UIScale = lcdHeightPx / 299`. Compact type sizes are the second number in the type table and never scale below 1.0. |
| **Portrait / square** | root taller than wide | Not redesigned. Keep today's stacked layout and take only the new tokens and components. |

`DeckLayout.resolve` stays the single owner of geometry. It returns the deck rect, `s`, the mode, and the rects in `shell.json` multiplied by `s`.

## 2. Tokens

### 2.1 Colour

**Glass layers** (the only panel style). Each leans toward the equipped faceplate's `deep` colour. This is the existing `DeckThemes` rule; `faceplates.json` → `ui` holds the results precomputed for all 16 plates.

| Token | Base | Lean toward `deep` | Scout result | Use |
|---|---|---|---|---|
| `panel` (glass) | `#15171B` | 14% | `#152525` | LCD background, sheets |
| `raised` | `#23262C` | 16% | `#213335` | Cards, secondary buttons, rows |
| `well` | `#0C0D10` | 10% | `#0D1818` | Board well, bar tracks, tab track, pills, icon wells |
| `selected` | `raised` → accent 14% | | | Selected card, row or tile |
| `line` | `#9AA0AA` → accent 35% | | | Dividers that need to show (rare) |

The LCD background also carries one vertical overlay gradient: white 3% at the top to black 12% at the bottom.

**Ink and text.** Text is always neutral. Never tint body text with the accent.

| Token | Value | Use |
|---|---|---|
| `text` | `#F3F4F6` | Titles, values, row titles |
| `soft` | `#C3C8D0` | Supporting lines, hints, idle tab labels |
| `dim` | `#8A909A` | Labels (caps eyebrows), captions, disabled |
| `ink` | `#0E0F12` | Text and glyphs on an accent or gold fill. Per plate: `faceplates.json` → `ink` (all 16 current plates use `#0E0F12`; lowest contrast is Night Orb at 8.25:1) |
| `stars` | `#FFC14D` | Stars icon, Star amounts, "ready to claim". Never tinted by the plate. |
| `danger` | `#FF5A6E` | Overflow line, Hard label, shortfall text. Always with a word. |
| `good` | `#7BE495` | Easy label only |
| `focus` | `#FFFFFF` | Focus ring |

**Deck-tint rules.**

1. The faceplate supplies `accent` (bright) and `deep` (dark). Nothing else from the plate reaches the UI.
2. `accent` is used for exactly five things: the selected tab pill, the primary button fill, progress fill, the selected stroke (2 px), and check marks. Plus the hardware: A cap, d-pad arrows, LED, boot ink.
3. Text on `accent` uses the plate's `ink`.
4. Semantic colours do not move with the plate: Stars gold, danger red, Easy/Medium/Hard = `good` / `stars` / `danger`.
5. `deep` only leans the three glass layers and the garden backdrop behind the deck.

`tint-variations.png` shows the same results screen under Scout, Ember, Tidepool and Night Orb.

### 2.4 Motion and sound

| Event | Motion | Time, easing | Sound cue | Reduced Effects |

| Tab switch | Pill slides under the label; content cross-fades | 140 ms, Quad Out | menu tick | Instant |

| Difficulty focus change | Card scales 1.00 → 1.03, multiplier chip pops | 120 ms, Back Out | `aim` pitched 0.9 / 1.0 / 1.15 | Instant |

## 3. Components

One constructor per component in `DeckArt`. Sizes are LCD px at `s = 1`. All states are drawn in `components.png`.

**State rules shared by everything**

| State | Rule |
|---|---|
| idle | As specified |
| hover | Fill mixed 6% toward white. Mouse only. |
| pressed | Content moves down 2 px; fill mixed 8% toward black. The hit rect does not move. |
| selected | `selected` fill and a 2 px `accent` stroke |
| disabled | Fill at 60% opacity, content in `dim` at 60%, no stroke, no lower edge. `Active = false`, `Selectable = false`. |
| focus (gamepad / keyboard) | The shared focus ring (2.3 above) around the control, plus the input glyph chip appears inside the button. Selected and focus can combine. |

**Minimum target** 44×44 px after scaling, everywhere. If a visible control is smaller (compact mode), grow an invisible hit frame around it.

### Button (secondary)
- **Size** 180×48 default; height 48 or 56 or 64 to match its primary neighbour. Radius 12.
- **Fill** `raised`, 1 px white 14% stroke. **Label** Heading 20, `text`, centred.
- **Glyph chip** (optional, left of the label, 10 px gap): 26 px circle, white 12% fill, white 27% 1 px stroke, letter Bold 14.
- **Variants.** Ghost: no fill or stroke until hover (white 6%). Destructive: `raised` mixed 10% toward `danger`, 1.5 px `danger` stroke, `danger` label.

### Primary button
- **Size** 200×56 (Start, Buy, Equip); 392×64 on results. Radius 12.
- **Fill** `accent`, label Heading 20 (22 on results) in the plate `ink`. 3 px lower edge. Glyph chip uses ink 18% fill, ink 35% stroke.
- **Pressed** the cap drops 2 px and the lower edge disappears. **Disabled** becomes the disabled secondary look (never a pale accent).
- At most one primary per screen.
- **Reward variant** (Claim): 120×38, fill `stars`, label Bold 16 in `#0E0F12`. Same states.

### Tab
- **Track** 520×44 for three tabs, radius full, `well`, 1 px stroke. Segments share the width minus 8.
- **Selected pill** inset 4 on all sides, `accent`; label Bold 17 in `ink`. Idle labels Bold 17 in `soft`.
- **Claim dot** 8 px `stars` circle, 9 px right of the label, 7 px above its centre.
- **Hover** label goes to `text`. **Disabled** label `dim` 60%.
- **Focus** ring around the selected pill. L / R shoulders switch tabs from anywhere on the screen.

### Card
- Radius 14, `raised`, 1 px stroke. Inner padding 20 (14 in the HUD).
- Label row first (Label 13, `dim`), then the value or title.
- A card is static unless it is a choice (difficulty cards, shop tiles); only choices take hover, pressed, selected and focus.

### Toggle
- 52×30, radius full. Off: `well` + stroke, knob 22 px `#C3C8D0` at x = 4. On: `accent`, knob in `ink` at x = 26.
- Knob travel 110 ms Quad Out. Disabled 47% opacity. Focus ring around the whole toggle.
- Label sits 12 px to the right, Body 16.

### Progress bar
- Height 8 in menus, 6 in the HUD, 4 in the HUD quest ticker. Radius full. Track `well`, fill `accent`; fill is never shorter than its height.
- A complete bar on a claimable quest turns `stars`.
- **Segmented** for counts ≤ 10: segments 20×10 (HUD) or 24×10, gap 4 to 6, radius 3; empty segments are `well` with the 1 px stroke.
- Count label to the right in Counter 13 or 14, `soft`.

### Toast
- Top centre of the **view** (not the LCD), y = 30. Height 48, radius full, width = content + 124.
- `well` fill, 1.5 px `stars` stroke, floating shadow. Check icon 22 in `stars`, text Bold 17 `text`, Star amount Counter 17 right-aligned 20 px from the edge.
- 2.4 s, one at a time, queue the rest. Never takes focus.

### Quest row
- **Size** 800×92, radius 14, `raised` + stroke.
- Icon well 56×56 at (16, 18), radius 14, `well`; icon 28.
- Title Bold 19 at (88, 16). Sub-line Small 14 `soft` at (88, 42).
- Progress bar at (88, 68), 466×8; count Counter 14 at x = 564, vertically centred on the bar.
- Reward `★ +N` Counter 18, right edge at x = 782, centred on y = 26.
- Action button 120×38 at (662, 44).

| State | Look | Action slot |
|---|---|---|
| In progress | As above | **Reroll** (secondary) only if progress is 0 and a reroll is left; otherwise empty |
| Ready | Fill `raised` mixed 7% toward gold, 2 px `stars` stroke, bar gold | **Claim** (reward button). This is where focus lands when the log opens. |
| Claimed | All content at 60%, icon becomes a check in `accent` | `CLAIMED` chip |
| Locked | Content at 60%, padlock icon, the reason in the sub-line | `LOCKED` chip |

### Back arrow
- A 56 px circle (44 in compact mode) at the **top right of the view**: right edge 24 px and top edge 24 px inside the safe insets (12 px in compact mode).
- Fill `#15171B` at 72%, 1.5 px white 24% stroke, floating shadow. Icon `back`, 26 px, `text`.
- Hover fill `#282B32` at 78%. Pressed drops 2 px and darkens. Disabled 35% (only during the boot's first 150 ms and while a save blocks leaving).
- It is in the gamepad focus order of no screen; **B / Esc / Backspace** is its shortcut. If keyboard focus reaches it (Tab), it takes the shared ring.
- Behaviour: start screen or results → leave to the garden. Mid-round → pause and leave (today's Lounge cap path). Quest log or shop → back one screen.

### List row (history, settings)
- 784×42 (pitch 44), radius 10, no fill at idle, a white 5% hairline under each row.
- Left column Counter 13 `dim` at x = 14; title Body 16 at x = 96; reward Counter 15 right-aligned at x = 738; check 18 at x = 762.
- Hover `raised` +6%. Selected `selected` + 2 px accent. Disabled 50%.
- Group headers are Label 12 `dim`, 30 px tall.

### Small parts
- **Wallet pill** height 40, radius full, `well` + stroke; star 22 at x = 24, amount Counter 18 right-aligned 18 px from the edge. Top right of every menu screen: right edge x = 824, y = 24.
- **Chip** height 26 (22 on the board and in strips), radius full, horizontal padding 10, Label 13 (11 when 22 high). Gold chips: `well` mixed 14% toward gold, gold text.
- **Hint bar** glyph chips 22 high (round for one letter, pill for words) then Small 14 `soft`; 18 px between pairs. Left edge x = 24.
- **Check circle** 22 px: done = `accent` disc with an `ink` check; open = 2 px `dim` ring.
- **Icons** `ui/icons.png`: 16 white icons in 64 px cells, drawn on a 24 grid with a 2 px stroke. Tint with `ImageColor3`. Rects in `ui-assets.json`.

### Gamepad and keyboard map

| Input | Gamepad | Keyboard | Touch |
|---|---|---|---|
| Move focus | D-pad / left stick | Arrow keys | Tap the target |
| Confirm | A | Enter / Space | Tap |
| Back | B | Esc / Backspace | Back arrow |
| Tabs | L1 / R1 | Q / E | Tap the tab |
| Quest log | Menu pill (Start / Select) | M | Tap MENU |

Focus never wraps. Hidden or covered screens leave the selection tree (`Selectable = false`), as `UI-DESIGN-SYSTEM.md` "Presentation ownership" already requires.

## 6. Boot
