# World 1 v7 import plan (2026-11-12)

Goal: players load onto the floating sky island instead of the old garden, safely, with the old world kept behind a flag.

Inputs: `artifacts/world1-mockup/v7/` (NOTES-v7.md, import-chunks.json, stations.json), `assets/art-source/environment/world1-mockup-v7-import.blend` (249 chunks, 73k tris), `sky/day` + `sky/night`.
Coordinates: Blender (x, y, z) = Roblox (x, z + 4, -y). Lawn top is Roblox Y 4, the same floor height as the legacy garden.

## Steps, in order

1. **Reduce chunks** (`scripts/build_world_v7_chunks.py`, background Blender, never the live session). Group the 249 chunks by collision class, region and material; join each group; split anything over 9k tris; split the backdrop so no MeshPart is wider than 2048 studs. Animated chunks are grouped by animation role (each chime, each pennant, lantern, mobile, islet groups, rock groups, lamp orbs, bubbles, crystals, water pieces, clouds). Each output mesh has its origin at its bounds centre. Writes `assets/world/world-v7.fbx` and `assets/world/world-v7-manifest.json` (name, material, tris, Roblox centre/size, collide class, anim). Also writes walkability data: perimeter wall boxes, cave blocker, fall catch, wet boxes for stream/pools, bridge span, ground heights.
2. **Export and upload.** FBX with axis_forward -Z, axis_up Y (as the baby/bear imports). Upload via Open Cloud (`POST /assets/v1/assets`, Model), poll, insert into Studio Edit, read back MeshId / MeshSize per part into `assets/world/world-v7-studio-import.json`. Upload the 17 surface textures and 12 sky faces as images.
3. **Mount.** `scripts/build_world_v7_assets.py` writes `assets/world/WorldAssets.rbxmx` (Model `WorldV7` of MeshParts, Size = MeshSize/100, InitialSize = raw MeshSize, TextureID per material), mounted at `ServerStorage.WorldAssets` by `default.project.json`. A world builder (`src/server/LoungeWorldV7Art.lua`) clones it into the `EggDropLounge` room at server start and sets: Anchored on all; CanCollide + PreciseConvexDecomposition on ground, rocks, architecture, station bodies, trunks; CanCollide off on leaves, flowers, water, decorations, backdrop, underside, anim pieces; invisible collidable PerimeterWall boxes and CaveBlocker; FallCatch as a server Touched volume that returns the player to spawn.
4. **Lighting.** Sky faces uploaded; `HollowClock` swaps the day/night `Sky` by daylight (threshold blend via two Sky instances is not possible, so it switches at dusk/dawn and leans on Atmosphere/ambient for the blend). Face orientation checked by screenshot and fixed if wrong.
5. **Animation.** New client module `WorldMotion.lua`: water scroll with `Texture` instances on the flat stream/pool parts, Beam-free falls via Texture OffsetStudsV on the fall MeshParts' overlay parts, bob for islets/rocks/bubbles, sway for chimes/pennants/lantern/mobile, pulse for glow parts. Distance-gated, throttled to 30 Hz, off when Reduced Motion is on.
6. **Gameplay positions.** `HollowWorldLayout` gains `WorldVersion = "v7"` (or `"legacy"`) and returns the version's layout: floor bounds, spawn (ArrivalDais), station frames (EggNest = Eggs, CareCradle = Journal/care machine, PocketDeckKiosk = Customize), toy lawn, rest anchors (three NapDais), lamps, walkable spans, routes. `GardenLayout`, `GardenCareLayout` and the station builders read from it. Legacy procedural scenery (LoungeArt meadow, greybox, spring, garden art) is built only when `WorldVersion == "legacy"`; v7 keeps only the functional station props (prompts, care machine supports) placed at the v7 frames.
7. **Pets walk the ground.** v7 walkability: floor bounds and ground ceiling from the measured heightmap; wet boxes along the stream, Lily pool, Falls pool and Sky Falls channel; blocked regions for the rotunda knoll and stairs, colonnade, hatch tree trunk, kiosk, rock walls, grotto; one bridge span (marble bridge, crossing along X). The rotunda is player-only. Rewrite GardenGreyboxWorld, WorldRoutes, GardenWalkability and GardenBridgeFollow specs for the new world.
8. **Verify in Studio Play** (fresh save, Space x5 for the Bear): spawn on island, every station, Bear follows and crosses the bridge, edge walls, FallCatch, cave blocked, rotunda walkable, no console errors.
9. **Screenshots** day and night, UI hidden: overview, spawn, hub with stations and Bear, rotunda, waterfall, edge -> `artifacts/world1-v7-import/`.
10. **Performance**: MeshPart count, tris, Stats memory vs the legacy world.

Fallback: if anything is unsafe, set `WorldVersion = "legacy"`, keep the v7 code behind the flag and list what is left.
